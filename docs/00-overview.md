# Homelab Overview

This document describes the **sanitized public architecture and operating principles** of the homelab.

Real infrastructure inventory and sensitive implementation details are intentionally maintained outside this public repository.

## Goals

- Build repeatable infrastructure documentation
- Keep public examples safe and sanitized
- Document security decisions before production use
- Make rebuild and recovery possible from notes and automation
- Keep public architecture useful without exposing unnecessary attack surface
- Separate operational inventory from public portfolio documentation

## High-Level Areas

- Compute and virtualization
- Network segmentation and DNS
- Identity and access
- Monitoring, logging, and alerting
- Backup and disaster recovery
- Automation and configuration management
- Secure remote access
- Documentation and change control

## Public Safety Rules

Do not publish real passwords, tokens, private keys, internal IP maps, public admin endpoints, sensitive hostnames, firewall/router/DNS exports, serial numbers, customer data, private inventory, or unsanitized screenshots/logs.

Use sanitized names and documentation networks in all public examples.
